# اللوح الذكي للكتابة والرسم في الهواء

**اللوح الذكي** نظام تفاعلي يحول كاميرا الويب التقليدية إلى أداة إدخال تتيح الرسم والكتابة في الهواء ضمن مساحة عمل رقمية، دون الحاجة إلى أجهزة إدخال إضافية أو عتاد متخصص، كبديل منخفض التكلفة للسبورات الذكية وأجهزة الرسم الرقمية.

يعتمد النظام على تتبع اليد بإطار العمل MediaPipe Hands مع خوارزميات المعالجة العددية وحساب المسافات الهندسية للتمييز بين الإيماءات، ويضيف بُعداً معرفياً عبر تحليل المعادلات الرياضية المكتوبة يدوياً.

## البيئة التقنية

- Python
- MediaPipe Hands
- OpenCV
- NumPy
- PIL
- Google Gemini API

## الوظائف التفاعلية

- **الرسم والكتابة:** تحويل حركة الأصابع إلى خطوط رقمية فورية.
- **تغيير الألوان والمسح:** أوامر إيمائية لاختيار اللون والمسح الجزئي أو الكامل.
- **حفظ النتائج:** تصدير محتوى اللوح بعد الانتهاء.
- **تحليل المعادلات:** دمج Google Gemini API لتحليل المعادلات الرياضية المكتوبة يدوياً واستخراج خطوات الحل وعرضها ضمن الواجهة.

## البنية التقنية

صُمم النظام ونُفذ بلغة Python بالاعتماد على OpenCV لمعالجة الفيديو الفورية، وMediaPipe لتقدير الوضعية وتتبع اليد، وNumPy وPIL ضمن المعالجة العددية وإدارة الصور، مع تكامل كامل مع Google Gemini API للجانب المعرفي.

## النتائج

أظهر التنفيذ العملي إمكانية تحقيق تفاعل طبيعي قائم على الإيماءات بكفاءة على أجهزة ذات مواصفات متوسطة، مع قابلية توسيع وظائف النظام نحو مهام معرفية إضافية تعزز قيمته التعليمية والتطبيقية.
