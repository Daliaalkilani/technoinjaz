# أداة API وMCP لتحويل Markdown إلى PDF

مشروع متكامل يعمل بالكامل على البنية السحابية **Serverless** عبر منصة Cloudflare، يوفر محرك تحويل عالي الأداء من Markdown إلى PDF يتجاوز قيود الأنظمة التقليدية في دعم اللغات ذات الاتجاه من اليمين لليسار (RTL) كالعربية، ودمج المخططات البيانية (PlantUML) والمعادلات الرياضية (LaTeX).

يعتمد النظام على واجهة برمجة تطبيقات REST وواجهة ويب تفاعلية، مع معالجة شاملة تبدأ بتحليل البيانات الوصفية (Frontmatter) وتنتهي بتوليد ملف PDF جاهز للطباعة والمشاركة.

## البيئة التقنية

- Cloudflare Workers
- Cloudflare Browser Rendering (Puppeteer)
- Cloudflare D1
- KaTeX
- Highlight.js
- PlantUML / SVG
- REST API
- MCP
- JWT

## خط التحويل

- **تحليل Frontmatter:** قراءة البيانات الوصفية للمستند وتوحيد إعداداته.
- **تحويل HTML مع تلوين الشيفرات:** عبر Highlight.js.
- **عرض المعادلات الرياضية:** بواسطة KaTeX مع دعم LaTeX.
- **دمج مخططات PlantUML:** جلبها من الخادم ودمجها كرسوميات متجهة SVG مدمجة للحفاظ على الجودة.
- **توليد PDF:** عبر Cloudflare Browser Rendering (Puppeteer) مع دعم RTL كامل وإظهار خلفيات الطباعة.

## الأمان وإدارة البيانات

معمارية أمنية متينة تشمل مصادقة المستخدمين (JWT) وتشفير كلمات المرور وإدارة سجل التحويلات عبر قاعدة بيانات D1، مع خيارات سمات متعددة لمظهر المخرجات.

## المخرجات

أثبت النظام قدرته على إنتاج مستندات PDF عالية الجودة بأزمنة استجابة مثلى، بما يجعله حلاً مثالياً للمطورين والكتّاب يلغي الحاجة إلى صيانة خوادم تقليدية، مع توافر الأداة كواجهة API وقناة MCP للتكامل مع أدوات الذكاء الاصطناعي.
