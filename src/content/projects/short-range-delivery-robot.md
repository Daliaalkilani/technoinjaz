# روبوت توصيل طلبات لمسافات قصيرة

مشروع تصميم وتنفيذ **روبوت متحرك منخفض التكلفة** لنقل الطلبات والأجسام الصغيرة ضمن مسافات قصيرة داخل البيئات المغلقة مثل المستشفيات والمختبرات والمكاتب والمؤسسات التعليمية، يجمع بين الحركة الآلية وذراع آلية لالتقاط الأجسام ونقلها.

يعالج المشروع ارتفاع تكلفة الأنظمة الروبوتية التجارية وتعقيدها، مقدماً نموذجاً أولياً عملياً يصلح للتطبيقات التعليمية والبحثية مع إمكانية تطويره مستقبلاً بإضافة الملاحة الذاتية وتجنب العوائق.

## البيئة التقنية

- Arduino Uno (ATmega328P)
- بيئة Arduino IDE
- محركات TT Gear Motor
- دائرة قيادة L293D
- محرك Servo
- وحدة HC-05 Bluetooth
- حساس HC-SR04
- بطارية ليثيوم + BMS

## المكونات والبنية

- **وحدة التحكم:** لوحة Arduino Uno كوحدة تحكم رئيسية.
- **الحركة:** أربعة محركات تيار مستمر (TT Gear Motors) عبر دائرة قيادة L293D.
- **الذراع الآلية:** ذراع مزودة بملقط (Gripper) يعمل بمحرك Servo لالتقاط الأجسام الصغيرة وإحكام الإمساك بها.
- **التحكم اللاسلكي:** وحدة HC-05 Bluetooth مع تطبيق هاتف للقيادة.
- **الاستشعار:** حساس HC-SR04 فوق صوتي لرصد المسافات.
- **التغذية:** بطارية ليثيوم مع دائرة حماية BMS.

## التكامل والتشغيل

جرى تصميم الهيكل الميكانيكي وبرمجة النظام باستخدام بيئة Arduino IDE لتحقيق التكامل بين المكونات الإلكترونية والميكانيكية، مع تنسيق حركة الروبوت وعمل الذراع الآلية أثناء تنفيذ عملية النقل، وواجهة تطبيق تتيح التحكم والمراقبة.

## نتائج الاختبار

أظهرت الاختبارات العملية قدرة الروبوت على تنفيذ عمليات الالتقاط والنقل بكفاءة واستقرار ضمن الحدود التصميمية المحددة: أرضيات مستوية داخلية وأجسام خفيفة تتناسب مع قدرة المحركات والذراع، دون الاعتماد على الذكاء الاصطناعي أو الملاحة الذاتية في النسخة الحالية.
