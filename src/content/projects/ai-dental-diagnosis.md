# تشخيص أمراض الفم والأسنان بالذكاء الاصطناعي

مشروع تطوير **نظام ويب ذكي لتشخيص أمراض الفم والأسنان** يعتمد على أحدث تقنيات الذكاء الاصطناعي والرؤية الحاسوبية، يقدم منصة تشخيصية تفاعلية تحلل الصور الرقمية (السريرية والشعاعية) بدقة وسرعة عاليتين.

يعتمد النظام في جوهره على نموذج لغوي رؤيوي (Vision-Language Model) متقدم يفهم الصورة سياقياً ويولّد تقريراً تشخيصياً أولياً باللغة العربية على هيئة JSON صارم، يتضمن الأمراض المكتشفة (مثل التسوس والتهاب اللثة والكسور) مع تحديد مواقعها بنظام الترقيم العالمي FDI.

## البيئة التقنية

- Vision-Language Model (Gemini)
- SAM — Segment Anything Model
- React 19
- TypeScript
- Flask
- Python
- SQLite
- FDI Numbering

## التقنيات الذكية

- **الفهم الرؤيوي السياقي:** نموذج VLM يحلل الصور ويولّد تقارير تشخيصية أولية مهيكلة.
- **التجزئة الدقيقة:** نموذج SAM من Meta يقص المنطقة المصابة على مستوى البكسل وينتج مضلعات (Polygons) تحدد حدود المرض تشريحياً بدقة تتجاوز الصناديق الإحاطية التقريبية.
- **موسوعة طبية تفاعلية:** مرجع للأمراض والمفاهيم داخل المنصة.
- **دعم بالمحادثة الآلية:** مركز دعم تفاعلي يجيب عن استفسارات المستخدمين.

## المعمارية البرمجية

معمارية حديثة تفصل الواجهة الأمامية عن الخلفية: الواجهة مبنية بـ React 19 وTypeScript مع خريطة أسنان تفاعلية ووضع داكن، والخادم الخلفي يعمل بـ Flask وPython لاستدعاء واجهات Gemini/Kimi السحابية وتشغيل نموذج SAM محلياً، مع قاعدة بيانات SQLite لإدارة سجلات المرضى والفحوصات.

## الأثر

يوفر التكامل بين النماذج السحابية متعددة الوسائط والتجزئة المحلية أداة تشخيصية مساعدة عالية الدقة تدعم اتخاذ القرار الطبي وتقلل الاعتماد على الفحص اليدوي، مع إمكانية التوسع ليشمل مزيداً من الأمراض والتحليلات المتقدمة.
