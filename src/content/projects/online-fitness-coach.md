# مدرب أونلاين ذكي Online Fitness Coach

**Online Fitness Coach** منصة تفاعلية تعتمد على الذكاء الاصطناعي التوليدي لتقديم استشارات رياضية دقيقة ومخصصة، سداً للفجوة بين التدريب المنزلي والاحترافية الرياضية، ومعالجةً للأخطاء الحركية التي تسبب الإصابات وضعف النتائج مع التعلم الذاتي عبر الإنترنت.

يعتمد النظام في جانبه الذكي بالكامل على Gemini API لتوليد خطط تدريبية مخصصة بناءً على البيانات الشخصية (العمر والوزن والطول والأهداف ومستوى النشاط)، دون الحاجة إلى أجهزة استشعار إضافية أو معالجة فيديو معقدة.

## البيئة التقنية

- Flutter / Dart
- Gemini API
- Cloudflare Workers
- Cloudflare R2
- Cloudflare D1
- الذكاء الاصطناعي التوليدي

## الوظائف الذكية

- **خطط تدريبية مخصصة:** تولّد آلياً وفق البيانات الشخصية والأهداف.
- **نصائح يومية ذكية:** إرشادات متجددة تناسب تقدم المستخدم.
- **تقارير تحليلية دورية:** متابعة التقدم وتحليل النتائج.
- **محادثة بلغة طبيعية:** التفاعل مع استفسارات المستخدمين نصياً.

## البنية السحابية

طُوّرت واجهة المستخدم بـ Flutter بلغة Dart لتجربة سلسة وسريعة الاستجابة، مع خادم خلفي على Cloudflare Workers يوفر حوسبة على الحافة تقلل زمن الاستجابة، وتخزين سحابي R2 للفيديوهات والملفات، وقاعدة بيانات علائقية D1 لإدارة المستخدمين والخطط والمواعيد.

## القيمة

توفر المنصة بيئة تدريبية تفاعلية ومنخفضة التكلفة تجمع بين سهولة الوصول وجودة التوجيه المدعوم بالذكاء الاصطناعي، بما يجعل التدريب الاحترافي في متناول المستخدم المنزلي.
