# تطبيق سياحي ذكي لتعزيز السياحة في سوريا

## ملخص المشروع

تطبيق سياحي رقمي يهدف إلى جمع خدمات استكشاف الوجهات السياحية، معلومات الفنادق، الحجوزات، المنتجات الحرفية، والمحتوى السياحي ضمن منصة واحدة. تم تطوير المشروع كمشروع تخرج في هندسة الحاسوب للعام 2024-2025، ويثبت خبرة فريق تكنو إنجاز والطلاب المشاركين في تصميم وتطوير حلول رقمية متعددة الأطراف.

**دور تكنو إنجاز:**
ساهمت تكنو إنجاز في دعم وتوجيه تطوير المشروع مع فريق الطلاب، ومراجعة الجوانب التقنية والتنظيمية للوصول إلى نموذج تطبيقي متكامل. (يجب تعديل هذه الفقرة لاحقًا لتطابق نطاق المساهمة الرسمي بدقة: تطوير كامل / إشراف / استشارة / مراجعة تقنية).

## نبذة عن المشروع

يعالج المشروع الحاجة إلى منصة رقمية تساعد المستخدم على اكتشاف الوجهات السياحية والخدمات المرتبطة بها، مع توفير تجربة تجمع بين الدليل السياحي، إدارة الحجوزات، عرض المنتجات الحرفية، والمحتوى السياحي.

تم بناء النظام حول تطبيق للمستخدم ولوحة إدارة تسمح بإدارة المحتوى والبيانات المرتبطة بالوجهات والفنادق والمنتجات والمقالات.

## نطاق أعمال تكنو إنجاز

> **يُفضل اعتماد هذا القسم بعد مراجعة Scope النهائي مع الفريق.**

يشمل نطاق العمل الموثق بعد الاعتماد النهائي:

- دعم التخطيط المعماري للحل الرقمي.
- مراجعة هيكل التطبيق وتقسيم مكوناته.
- دعم تطوير تطبيق الهاتف ولوحة الإدارة حسب نطاق التكليف.
- مراجعة تكامل الواجهة الأمامية مع الخادم وقاعدة البيانات.
- تحسين تنظيم تجربة المستخدم ومسارات الاستخدام.

## مكونات النظام

### تطبيق المستخدم

يتضمن:

- استعراض الوجهات السياحية.
- عرض معلومات المواقع.
- استعراض الفنادق.
- الحجوزات.
- المنتجات والحرف اليدوية.
- المقالات السياحية.
- المفضلة.
- التنبيهات.

### لوحة التحكم

تتيح إدارة:

- المستخدمين.
- الوجهات السياحية.
- الفنادق والغرف.
- المنتجات.
- المقالات.
- الطلبات.
- المحتوى.

## البنية التقنية

تم تصميم النظام باستخدام:

- Flutter لتطوير تطبيق الهاتف.
- Laravel لبناء الجانب الخلفي وواجهات API.
- MySQL لتخزين البيانات.
- Bootstrap لتطوير واجهات الإدارة.

تعتمد البنية على فصل التطبيق عن الخادم وقاعدة البيانات لتسهيل تنظيم البيانات وتطوير الوظائف المستقبلية.
