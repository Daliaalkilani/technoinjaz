# تطبيق سياحي ذكي لتعزيز السياحة في سوريا

## ملخص المشروع

تطبيق سياحي رقمي يهدف إلى جمع خدمات استكشاف الوجهات السياحية، معلومات الفنادق، الحجوزات، المنتجات الحرفية، والمحتوى السياحي ضمن منصة واحدة. تم تطوير المشروع كمشروع تخرج في هندسة الحاسوب للعام 2024-2025، ويثبت خبرة فريق تكنو إنجاز والطلاب المشاركين في تصميم وتطوير حلول رقمية متعددة الأطراف.

**دور تكنو إنجاز:**
ساهمت تكنو إنجاز في دعم وتوجيه تطوير المشروع مع فريق الطلاب، ومراجعة الجوانب التقنية والتنظيمية للوصول إلى نموذج تطبيقي متكامل.

---

## حقائق المشروع

| العنصر | التفاصيل |
|---|---|
| نوع المشروع | منصة سياحية رقمية متعددة الوظائف |
| القطاع | السياحة والتقنيات الرقمية |
| السنة | 2024-2025 |
| المنصة | تطبيق هاتف + لوحة تحكم إدارية |
| Frontend | Flutter / Dart |
| Backend | Laravel / PHP |
| قاعدة البيانات | MySQL |
| المستخدمون | سائح، حرفي، مدير نظام |
| الحالة | نموذج تطبيقي منفذ |

---

## نبذة عن المشروع

يعالج المشروع الحاجة إلى منصة رقمية تساعد المستخدم على اكتشاف الوجهات السياحية والخدمات المرتبطة بها، مع توفير تجربة تجمع بين الدليل السياحي، إدارة الحجوزات، عرض المنتجات الحرفية، والمحتوى السياحي.

تم بناء النظام حول تطبيق للمستخدم ولوحة إدارة تسمح بإدارة المحتوى والبيانات المرتبطة بالوجهات والفنادق والمنتجات والمقالات.

---

## نطاق أعمال تكنو إنجاز

شمل نطاق عمل تكنو إنجاز:

- دعم التخطيط المعماري للحل الرقمي.
- مراجعة هيكل التطبيق وتقسيم مكوناته.
- دعم تطوير تطبيق الهاتف ولوحة الإدارة حسب نطاق التكليف.
- مراجعة تكامل الواجهة الأمامية مع الخادم وقاعدة البيانات.
- تحسين تنظيم تجربة المستخدم ومسارات الاستخدام.

---

## مكونات النظام

### تطبيق المستخدم

يتضمن:

- استعراض الوجهات السياحية.
- عرض معلومات المواقع.
- استعراض الفنادق.
- الحجوزات.
- المنتجات والحرف اليدوية.
- المقالات السياحية.
- المفضلة.
- التنبيهات.

### لوحة التحكم

تتيح إدارة:

- المستخدمين.
- الوجهات السياحية.
- الفنادق والغرف.
- المنتجات.
- المقالات.
- الطلبات.
- المحتوى.

---

## البنية التقنية

تم تصميم النظام باستخدام:

- Flutter لتطوير تطبيق الهاتف.
- Laravel لبناء الجانب الخلفي وواجهات API.
- MySQL لتخزين البيانات.
- Bootstrap لتطوير واجهات الإدارة.

تعتمد البنية على فصل التطبيق عن الخادم وقاعدة البيانات لتسهيل تنظيم البيانات وتطوير الوظائف المستقبلية.

---

## التحديات والحلول

### التحديات

- تنظيم أنواع متعددة من البيانات السياحية.
- إدارة العلاقة بين المستخدمين والخدمات المختلفة.
- تصميم تجربة استخدام تجمع عدة وظائف في تطبيق واحد.

### الحلول

- تصميم قاعدة بيانات مترابطة.
- فصل التطبيق عن الخادم.
- بناء لوحة إدارة لإدارة المحتوى.

---

## النتائج

النتيجة الأساسية للمشروع هي بناء نموذج تطبيقي يجمع بين:

- تطبيق مستخدم.
- Backend.
- قاعدة بيانات.
- لوحة إدارة.
- محتوى سياحي ومنتجات وحجوزات.

لا تتوفر بيانات تشغيلية لقياس أثر اقتصادي أو زيادة فعلية في السياحة.

---

## الخدمات المرتبطة

- تطوير تطبيقات الهاتف.
- تطوير المنصات الرقمية.
- تطوير الأنظمة الخلفية وواجهات API.

هل تخطط لمنصة رقمية تجمع خدمات متعددة وتجربة مستخدم متكاملة؟ يمكن لفريق تكنو إنجاز مناقشة متطلبات المشروع وبناء الحل المناسب حسب نطاق العمل.
