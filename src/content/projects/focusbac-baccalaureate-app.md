# تطبيق FocusBac التعليمي لطلاب البكالوريا

**FocusBac** تطبيق تعليمي رقمي مجاني موجه لطلاب البكالوريا في الفرعين العلمي والأدبي، يقدم بيئة تعلم تفاعلية ومنظمة تعالج كثافة المناهج وتشتت المصادر، مع آلية تعلم تراكمي تقتضي اجتياز اختبارات الدروس لفتح الدروس اللاحقة.

يعتمد التطبيق على مفهوم التعلم المصغر (Microlearning) بتقديم المحتوى على شكل مقاطع قصيرة ومركزة، مع أسلوب تحفيز بالألعاب (Gamification) عبر تتبع التقدم ومنح النقاط لتعزيز دافعية الطلاب واستمرارية التفاعل.

## البيئة التقنية

- Flutter / Dart
- Laravel (PHP)
- MySQL
- Filament
- Eloquent ORM
- RESTful API
- التخزين المؤقت Caching

## آلية التعلم التراكمي

- **التعلم للإتقان:** لا ينتقل الطالب إلى الدرس التالي إلا بعد اجتياز اختبار قصير مرتبط بالدرس الحالي بالنسبة المطلوبة.
- **محتوى مقسم ومدروس:** تفكيك المنهج إلى وحدات صغيرة وواضحة تساعد على الحفاظ على التركيز.
- **متابعة التقدم:** عرض النقاط والإنجازات كتغذية راجعة فورية تعزز التعلم المنظم ذاتياً.
- **تنظيم وقت الدراسة:** مسار تعليمي واضح يخفف الضغط والفوضى قبل الامتحانات.

## إدارة النظام والمحتوى

يوفر النظام لوحة تحكم إدارية لإدارة المستخدمين وتصنيف المواد الدراسية وإدارة الفروع والروابط التعليمية، مع مصادقة كاملة وتتبع تقدم كل طالب وتقارير متابعة.

## البنية التقنية

طُوّرت الواجهات بـ Flutter لتعمل على Android وiOS، مع خلفية Laravel تعتمد نمط MVC وEloquent ORM ولوحة Filament الإدارية، وقاعدة بيانات علائقية تُدار عبر الترحيلات (Migrations)، وتواصل RESTful API بين العميل والخادم مع تخزين مؤقت (Caching) لتحسين الأداء.
