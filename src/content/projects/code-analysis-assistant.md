# مساعد برمجي لتحليل الشيفرات البرمجية وتقييم نماذج توليد الكود

مشروع تصميم وبناء **منصة متكاملة (EHCode Hub)** تعمل كحاضنة تقييم (Benchmark Harness) لمقارنة قدرات نماذج توليد الكود الرائدة في مهام برمجية واقعية ومتنوعة، استجابةً للتزايد المطرد في استخدام نماذج الذكاء الاصطناعي التوليدية لأتمتة كتابة الأكواد.

صُممت عشرون مهمة برمجية موحدة تتوزع على عشر فئات تطويرية تشمل تطبيقات الويب المتكاملة، وواجهات برمجة التطبيقات، والواجهات الأمامية، وتطبيقات بايثون، والتجارة الإلكترونية، وتصور البيانات، والنمذجة ثلاثية الأبعاد، وتطبيقات الجوال بـ Flutter، وأدوات الأتمتة.

## البيئة التقنية

- Node.js (وحدات مدمجة)
- iframe
- Playwright
- Benchmark Harness
- نماذج توليد الكود
- opencode

## مكونات المنصة

- **خادم عارض تفاعلي:** مبني بـ Node.js اعتماداً حصرياً على وحداته المدمجة دون أي اعتماديات خارجية.
- **واجهة أمامية ديناميكية:** استعراض النتائج ومقارنة مخرجات النماذج.
- **مساعد برمجي ذكي:** دمج EHCode/opencode عبر نافذة iframe داخل المنصة.
- **مشغل موحد:** إقلاع كافة المكونات في الخلفية بنقرة واحدة.

## منهجية التقييم

توفر المنصة بيئة موضوعية ومتكررة لمقارنة أداء نماذج توليد الكود عبر مهام موحدة، بما يسمح باستخلاص مؤشرات قابلة للقياس حول جودة المخرجات واكتمالها في فئات تطويرية مختلفة، ويدعم دراسات اختيار النموذج الأنسب لكل نوع مهمة.

## الأثر

يمثل المشروع أداة عملية لفرق التطوير والباحثين لتقييم نماذج توليد الشيفرات البرمجية بشكل منظم، ويسهم في رفع جودة قرارات تبني أدوات الذكاء الاصطناعي في دورة تطوير البرمجيات.

## هل تخطط لنظام مشابه؟

إذا كنت تعمل على أداة ذكية لتحليل الشيفرات البرمجية وتحتاج إلى مساعدة تقنية في تطوير الفكرة أو بناء نموذج أولي، يمكن التواصل مع **مكتب تكنو إنجاز** لمناقشة متطلبات المشروع ونطاق الدعم المناسب.
