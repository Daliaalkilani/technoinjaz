# Developing a System for Detecting Misconduct in Exam Halls Using Computer Vision Technologies

## Project Summary

Techno Enjaz participated in supporting the development of this academic project in collaboration with the student team, with the goal of building a prototype based on computer vision and artificial intelligence techniques to monitor behavioral indicators that may be associated with misconduct during exams.

The system relies on analyzing the frames coming from the camera using techniques such as YOLO for person detection and MediaPipe for extracting face and body landmarks and analyzing movement. The current model focuses on analyzing head orientation and selected motion indicators: head deviation from the forward position is classified as a state that warrants review, while a forward orientation represents a normal state within the test scenario.

The project is a prototype tested in a controlled environment — not an operational system deployed in actual exam halls.

## How the System Works

1. Capturing frames from the camera.
2. Locating the person in the scene using the detection model.
3. Extracting the required face/body landmarks.
4. Analyzing head orientation and movement.
5. Displaying the test status visually.

------------------------------------------------------------------------

## Technical Challenges

- Variations in lighting and camera angles.
- The need to distinguish natural behavior from movement that may warrant review.
- The need for broader testing in real, multi-user environments.
- Improving the tracking of fine movements and reducing false states.

------------------------------------------------------------------------

## Results

The prototype demonstrated the ability to classify states related to head orientation within the test environment. No accuracy percentages or numeric performance indicators are presented, because no official measurement report specific to the project is available.

------------------------------------------------------------------------

## Project Limitations

The system does not prove that cheating has occurred; it monitors visual indicators that may require human review.
