# Multi-Link Ground Robot Prototype with Remote Control and Computer Vision

## Project Summary

The project team developed a ground robot prototype combining embedded control systems, wireless communications, and image processing. The prototype aims to test the integration of remote operation, camera image transmission, and electronic component control within a single robotic platform.

The project was carried out as part of an academic project titled **"Design and Implementation of a Robot for Special Tasks"** in the Communications Engineering field for the 2024–2025 academic year.

**Techno Enjaz** contributed to supporting the students during the project's development through technical assistance in building the prototype and integrating its components.

## System Components

The prototype is built from a set of engineering elements including:

- Arduino UNO to control the components.
- L298N motor driver board.
- DC motors for movement.
- HC-05 Bluetooth module for wireless control.
- A camera linked to image processing.
- Python for data and image processing.
- Wireless link modeling and analysis components using CST.

---

## How the System Works

The system operates through the integration of several layers:

1. Receiving control commands from the control interface.
2. Sending the commands to the Arduino controller.
3. Driving the robotic platform's movement through the driver board and motors.
4. Transmitting the camera images to the computer for software processing.
5. Analyzing the visual data within the computer vision environment.

---

## Computer Vision and Communications

The project used image processing and computer vision as part of its systems-integration experiment, relying on a computer-connected camera for image analysis.

The HC-05 communication module's characteristics were also analyzed using electromagnetic simulation in CST to study the antenna's properties and behavior within the system.

---

## Results

The prototype succeeded in:

- Operating a remotely controlled robotic platform.
- Integrating more than one communication link within a single prototype.
- Transmitting images from the camera to the processing environment.
- Testing hardware–software integration within a prototype.

The project is not considered an operational field system or a finished product — it is an engineering prototype for testing the integration between components.

---

## Engineering Challenges

The project faced challenges related to:

- Integrating several electronic modules on a single platform.
- Wireless link stability.
- Image processing within a limited computing environment.
- Coordinating the relationship between embedded control and external software.
