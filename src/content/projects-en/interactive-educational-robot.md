# Interactive AI Educational Robot for Children

A design-and-development project for an **interactive educational robot for children** built on AI and computer vision to enhance early learning: the robot interacts with the child through a digital camera recognizing numbers, English letters, fruits, and colors.

For extra engagement, the robot includes servo motors enabling interactive movements, plus pre-generated educational voice clips played automatically after each recognition.

## Technical Environment

- Python
- OCR
- HSV Color Model
- Pre-trained ML Models
- Servo Motors
- ElevenLabs
- Digital Camera

## Recognition capabilities

- **Numbers and English letters:** via optical character recognition (OCR).
- **Colors:** using the HSV model accurately under varying lighting conditions.
- **Fruits and educational objects:** with pre-trained machine learning models.
- **Voice interaction:** audio clips generated with the ElevenLabs platform using a custom robot voice.

## Physical interaction

The robot is equipped with three servo motors — one for the arm and two for the legs — allowing interactive movements that make learning more attractive and keep the child engaged.

## Methodology and results

The project followed a structured methodology covering requirements analysis, data collection, model development, and performance evaluation. Results demonstrated suitable recognition accuracy and an effective interactive learning experience supporting cognitive skill development in early childhood.
