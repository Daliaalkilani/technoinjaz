# AI-Based Breast Cancer Diagnosis

An intelligent **breast cancer diagnosis system** combining medical image analysis using the YOLO algorithm with laboratory data analysis via classifiers such as Random Forest — a comprehensive approach that leverages both visual and numerical data for more accurate, reliable outcomes.

Test results showed the system achieving high prediction accuracy while reducing human error and processing time, making it an effective tool supporting physicians in the diagnostic process.

## Technical Environment

- YOLO
- Random Forest
- Python
- Medical Image Analysis
- Machine Learning
- Data-Entry Interfaces

## Two complementary analysis tracks

- **Visual analysis:** YOLO detects tissues and abnormal regions in radiology images.
- **Numerical analysis:** classification algorithms such as Random Forest process laboratory test data.
- **Result fusion:** the comprehensive approach combines both tracks' outputs for a better-supported diagnostic decision.
- **Flexible input:** easy-to-use interfaces accept data via images or Excel files.

## Interface and usability

The system's interfaces are designed for ease of use, offering flexible data entry and clear result presentation — easing integration into medical institutions and fitting physicians' workflow without a steep learning curve.

## Impact

The system improves diagnostic quality and supports early medical decisions, providing a model for applying AI to medical imaging and laboratory analysis within a single pipeline.
