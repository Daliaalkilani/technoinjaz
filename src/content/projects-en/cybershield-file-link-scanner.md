# CyberShield — AI-Powered File & Link Security Scanner

**CyberShield** is a smart mobile app that strengthens user security when handling files and web links, pairing a trustworthy security scan with simplified explanations that help non-technical users understand the risk level and act accordingly.

The app integrates several cloud services: VirusTotal performs the multi-engine security scan, while artificial intelligence generates simplified summaries and explains scan results in plain language.

## Technical Environment

- VirusTotal API
- Generative AI
- Mobile Applications
- Cybersecurity
- Malicious Link Analysis

## App capabilities

- **File scanning:** analyzing files against multi-engine security databases before opening or sharing them.
- **Link scanning:** detecting malicious and phishing links before they are visited.
- **AI explanations:** summarizing technical scan results and explaining them in simple, non-specialist language.
- **Action guidance:** steering the user to the right next step based on the risk level.

## User experience

The app is designed with a clear, simple interface so any user can scan their content without security expertise, presenting results as understandable summaries rather than raw technical reports.
