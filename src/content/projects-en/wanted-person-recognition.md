# Wanted-Person Recognition Using Deep Learning

An intelligent surveillance system for **enhancing security and safety in public spaces**, improving on traditional monitoring through continuous, effective monitoring and real-time visual data analysis — focused on recognizing wanted individuals from a pre-built list and triggering immediate alerts upon detection.

The system relies on a network of cameras distributed across multiple locations running image-processing and deep-learning algorithms, delivered as an extensible prototype for critical venues such as airports, shopping centers, and border crossings.

## Technical Environment

- Python
- Deep Learning
- Computer Vision
- Face Recognition
- Object Detection
- SQLite
- Anaconda / Jupyter

## How the system works

- **Instant capture and analysis:** camera frames processed rapidly with computer-vision techniques.
- **Wanted-list matching:** recognizing individuals against a pre-built database.
- **Real-time alerts:** immediate notification on a match, without direct human intervention.
- **Database management:** interfaces for managing person records and recognized/unrecognized events.

## Technical architecture

The system is developed in Python within Anaconda and Jupyter Notebook environments, with an SQLite database for record management, and object-detection and face-recognition algorithms in an integrated pipeline documenting both successful and failed recognition cases.

## Problems addressed

- **Automated surveillance:** reducing reliance on slow, error-prone human review.
- **Wider coverage:** a camera network spanning far more than manual monitoring.
- **Faster response:** instant detection and alerting instead of delayed manual analysis.
- **Lower cost:** an economical alternative to around-the-clock human monitoring.
