# Electronic Voting System — Developing a Web Platform for Digital Voting Management

## Project Summary

Techno Enjaz participated in supporting and developing the **Electronic Voting System** project in collaboration with the student team, with the goal of building a web platform prototype for managing a complete digital voting cycle covering user registration, candidate management, candidacy requests, the voting process, and an administration dashboard.

The system is built on web development technologies using **Laravel** and **Bootstrap**, with a multi-role architecture comprising three roles: voter, candidate, and system administrator. The project focuses on organizing the electoral workflow within a single platform — from account creation and candidacy requests through to voting and results review.

## System Concept

The system aims to digitize the steps of the voting process through an electronic platform that brings together:

- User registration.
- Candidacy request management.
- Creating candidate profiles.
- Displaying candidate information to voters.
- Carrying out the voting process with a confirmation step.
- System administration and results monitoring.

---

## How the System Works

### 1. Users

The system includes three main categories:

### The Voter

Can:

- Create an account.
- Log in.
- Browse candidates.
- View their information.
- Select a candidate and confirm the vote.

### The Candidate

After submitting a candidacy request and receiving administrative approval, can:

- Manage their personal profile.
- Add biographical information.
- Display their résumé and campaign content.

### The Administrator (Admin)

Can:

- Review candidacy requests.
- Accept or reject requests.
- Manage candidate profiles.
- Monitor the voting process.
- Review the results.

---

## Project Limitations

The system is an academic application prototype — not a governmental election system or an officially accredited electoral platform — and it is not presented as guaranteeing ballot secrecy or full security before undergoing security testing and obtaining independent certifications.
