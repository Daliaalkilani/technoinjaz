# Smart Tourism Application for Promoting Tourism in Syria

## Project Summary

A digital tourism application that aims to bring together destination exploration services, hotel information, bookings, artisan products, and tourism content within a single platform. The project was developed as a computer engineering project for 2024–2025, and it demonstrates the experience of the Techno Enjaz team and the participating students in designing and developing multi-sided digital solutions.

**Techno Enjaz's role:**
Techno Enjaz contributed to supporting and guiding the project's development alongside the student team, and to reviewing the technical and organizational aspects to reach a complete working prototype.

## About the Project

The project addresses the need for a digital platform that helps users discover tourist destinations and the services associated with them, providing an experience that combines a tourism guide, booking management, artisan product display, and tourism content.

The system was built around a user-facing application and an administration dashboard that allows managing the content and data associated with destinations, hotels, products, and articles.

## Technical Architecture

The system was designed using:

- Flutter for developing the mobile application.
- Laravel for building the back end and API interfaces.
- MySQL for data storage.
- Bootstrap for developing the administration interfaces.

The architecture relies on separating the application from the server and the database to make it easier to organize the data and develop future functionality.

## Challenges and Solutions

### Challenges
