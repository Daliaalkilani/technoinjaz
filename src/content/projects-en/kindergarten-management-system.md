# Kindergarten Management System with Flutter and Laravel

A project to design and develop an **integrated kindergarten management system** aimed at improving operational efficiency and enhancing communication between the kindergarten administration and parents, with a unified mobile interface built with **Flutter** and a robust **Laravel** back-end.

## Project Idea

The system revolves around three main roles:

- **Parent:** following the child's academic and health progress, viewing activities and events, and communicating directly with the administration.
- **Child:** attendance records, health reports, and behavioral notes.
- **Administration:** tools for managing children's data, classrooms, announcements, and daily schedules.

## Technical Architecture

The project relies on a modern architecture that separates the front-end from the business logic:

- **Flutter** for building an interactive, unified mobile front-end.
- **Laravel (PHP)** for building the back-end functionality and managing data and operations.
- A comprehensive API documented according to **OpenAPI (YAML)** standards to ensure scalability and future integration.

This separation of layers allows the mobile app and the back-end services to evolve independently, and opens the door to adding other interfaces in the future, such as a web dashboard for the administration.

## Key Features

- Managing children's records, classrooms, and daily schedules.
- Tracking daily attendance and generating reports.
- Health records and behavioral notes for each child.
- Announcements and events delivered directly to parents through the app.
- A direct communication channel between parents and the administration.

## Project Results

The project produced a working platform covering the kindergarten's complete workflow, from attendance tracking to communication with families, with Flutter interfaces covering all aspects of the system and a documented API that allows future expansion.

## Development Opportunities

Future enhancements could include intelligent, well-designed notifications, analytical reports on children's progress, support for multiple kindergartens within a single system, and integration with payment gateways for fees.
