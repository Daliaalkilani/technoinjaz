# Robotic Hand for Motion Control via Computer Vision and Hand Tracking

## Project Summary

The project team developed a robotic hand prototype that mimics certain states of human hand movement by combining computer vision with embedded control systems. The system captures hand motion through the camera, analyzes the state of the fingers, and converts the results into control commands sent to the controller that drives the servo motors.

The project was carried out in an academic setting and demonstrates the concept of human–robot interaction by turning visual gestures into mechanical movement of the robotic hand.

## System Concept

The system captures and analyzes human hand motion using hand-tracking techniques, then converts the state of the fingers into control signals that direct the servo motors inside the robotic hand.

## How It Works

1. Capturing the hand's image through the camera.
2. Analyzing the hand's keypoints and finger states.
3. Converting the detected state into control commands.
4. Sending the commands to the control unit.
5. Actuating the servo motors to reproduce the desired state of the hand.

## Main Components

- Arduino UNO as the control unit.
- Servo motors to move the hand's parts.
- HC-05 Bluetooth module for wireless communication.
- A camera to capture hand motion.
- A computer vision system based on hand tracking.
