# Code Analysis Assistant for Evaluating Code-Generation Models

A project designing and building an **integrated platform (EHCode Hub)** acting as a benchmark harness for comparing leading code-generation models on realistic, varied programming tasks — a response to the steady rise of generative AI models automating code writing.

Twenty unified coding tasks were designed across ten development categories, including full-stack web apps, APIs, frontends, Python applications, e-commerce, data visualization, 3D modeling, Flutter mobile apps, and automation tooling.

## Technical Environment

- Node.js (built-in modules)
- iframe
- Playwright
- Benchmark Harness
- Code-Generation Models
- opencode

## Platform components

- **Interactive viewer server:** built with Node.js relying exclusively on its built-in modules — zero external dependencies.
- **Dynamic frontend:** browsing results and comparing model outputs.
- **Intelligent coding assistant:** EHCode/opencode embedded via an iframe inside the platform.
- **Unified launcher:** starting all background components with a single click.

## Evaluation methodology

The platform provides an objective, reproducible environment for comparing code-generation model performance across unified tasks, enabling measurable indicators of output quality and completeness per development category and supporting studies on picking the right model per task type.

## Impact

The project gives development teams and researchers a practical tool for systematically evaluating code-generation models and improves decisions about adopting AI tooling in the software development lifecycle.
