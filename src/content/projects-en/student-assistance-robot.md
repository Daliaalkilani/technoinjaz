# AI Student Assistance Robot with Touchscreen

A design-and-implementation project for an **intelligent robot with an interactive touchscreen** serving as an electronic assistant for students in educational institutions, offering academic and administrative services: student registration, information lookup, data updates, official document generation and printing, and answering frequently asked questions about student affairs and exams.

The system uses AI and natural language processing for easy, effective interaction via text or voice commands, with full Arabic support.

## Technical Environment

- Artificial Intelligence
- Natural Language Processing (NLP)
- Central Database
- Web Services
- Interactive Touchscreen
- Arabic Voice Support

## Services provided

- **Registration and data management:** enrolling new students and updating records automatically.
- **Inquiry:** information lookup and answers to common questions about student affairs and examinations.
- **Document generation:** creating official documents and printing them directly from the robot.
- **Multimodal interaction:** touchscreen plus voice and text input with AI-backed responses.

## Software architecture

The system is built on a central database and an Arabic-supporting interactive interface, integrating AI services to analyze inquiries, understand user requests, and deliver appropriate responses, with a modern architecture combining local databases, web services, and NLP technologies.

## Results

Practical tests showed the system efficiently executing its tasks, streamlining administrative procedures and reducing the time and effort needed for student services, with a working robot prototype operating via its touchscreen in a real usage environment.
