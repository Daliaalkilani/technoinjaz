# Face-Recognition Student Attendance with Session Timer

An integrated system for **recording student attendance using facial recognition** with a built-in timer defining the allowed arrival window, using AI to verify each student's identity accurately and log their status based on actual arrival time.

The system addresses the shortcomings of traditional methods — fraud, delays, and time waste — while guaranteeing fairness and transparency in attendance tracking.

## Technical Environment

- Face Recognition
- Artificial Intelligence
- Machine Learning
- Session Timer
- Face-Comparison Engine

## Smart attendance rules

- **Session timer:** a defined allowed-arrival window per lecture.
- **Automatic lateness:** any student arriving after the cutoff is marked absent automatically.
- **Outsider blocking:** the system refuses attendance records for anyone not in the session.
- **Auto-reset:** when the lecture ends, data is cleared in preparation for the next session.

## Technical architecture

The system relies on face-recognition algorithms and a difference engine for face comparison, with a documented system architecture and flow diagram governing the data path from capture to registration.

## Impact

The system delivers accurate, fair attendance records that reduce fraud and impersonation, easing the manual administrative burden on instructors and administration.
