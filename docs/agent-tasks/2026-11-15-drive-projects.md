# مهمة: إضافة مشاريع وحلقات جديدة من Google Drive إلى موقع تكنو إنجاز

## السياق
- الموقع: technoenjaz.com — Next.js 15 على Cloudflare Workers. مجلد العمل: `/root/technoinjaz`.
- **ابدأ بـ `git fetch origin && git rebase origin/main`** — نسخة GitHub هي السلطة.
- محتوى Google Drive نُزّل محلياً بالكامل:
  - الشجرة الأصلية: `/root/technoinjaz-drive-input/TechnoEnjaz/مشاريع 2024-2025/...` (55 ملف)
  - الملفات المتبقية (مسطحة، اسم الملف = اسم المشروع): `/root/technoinjaz-drive-input/_flat/` (~186 ملف: docx/pdf/pptx)
  - أغلب ملفات `_flat` من السنة الجديدة «مشاريع 2025 - 2026» (جامعات: الافتراضية السورية، العربية الخاصة، الوطنية الخاصة، الحواش، القلمون، حلب، حماة، حمص، معهد تقنيات الحاسوب بحماة) والباقي مكملات 2024-2025 (منها حلقات بحث).
- استخرج النصوص فعلياً (python-docx / pdftotext / python-pptx — متاحة عبر pip إذا ناقصة) واقرأ محتوى كل ملف قبل كتابة أي عنصر. لا تكتب من أسماء الملفات وحدها إلا إذا فشل استخراج النص كلياً (وثّق ذلك).

## المهمة
1. **جرد ومقارنة (إلزامي قبل أي إضافة):**
   - المشاريع الحالية: `src/data/projectsData.ts` — الحقل `folderName` يقابل اسم مجلد/ملف المشروع بالعربي، و`title` العنوان الموسّع.
   - المقالات الحالية (حلقات البحث): `src/data/blogArticlesData.ts`.
   - **لا تكرر أي عنصر موجود** — قارن بـ`folderName`/`slug`/تشابه العنوان (نفس المشروع بنفس الجامعة). مشروع موجود بنسخة «معدل»/«نهائي» لا يُضاف مرتين.
2. **أضف الجديد فقط:**
   - **مشاريع تخرج/فصلية جديدة** → `projectsData.ts` بنفس بنية `ProjectItem` حرفياً وكل حقولها (slug إنجليزي واصف, title, titleEn, excerpt, excerptEn, category من المسميات الموجودة, categoryNameAr/En, seoTitle/En ≤60 حرف عربي, metaDesc/En, h1/h1En, altText/En, folderName/En, image, tags/En, pdfUrl إن وجد PDF).
   - **حلقات بحث جديدة** → مقالات في `blogArticlesData.ts` بنفس البنية كاملة (author من فريق تكنو إنجاز المناسب، publishDate اليوم 2026-11-15، readTime محسوبة، content عربي غني بعناوين فرعية H2/H3 وقوائم، contentEn كامل مترجم، tags عربية + tagsEn).
3. **الصياغة SEO/GEO** بالأسلوب المعتمد بالموقع: عنوان بحثي/تساؤلي طبيعي، جواب مباشر بأول فقرة يليق بمقتطفات محركات ووكلاء الذكاء الاصطناعي (GEO)، مصطلحات تقنية دقيقة من محتوى المشروع نفسه، alt text وصفي، لا حشو ولا مبالغة تسويقية.
4. **صور أغلفة للمشاريع الجديدة فقط:** اكتب برومبت لكل مشروع جديد (ومقال جديد إذا احتاج غلافاً) بنفس ستايل `docs/image-prompts/new-project-covers.md` حرفياً (اقرأه أولاً): مشهد واقعي ليلي كحلي غامق سينمائي 16:9، أجهزة حقيقية على مكتب/موقع هندسي، خطوط هولوغرافية نيلي/بنفسجي/سماوي ولمسات كهرمانية، **بدون أي نص أو كتابة**، الثلث السفلي غامق فاضي. اجعل البرومبت خاصاً بموضوع المشروع نفسه (متل الأمثلة الموجودة). أضفها في `docs/image-prompts/new-project-covers-2.md` مع الـslug بجانب كل عنوان. **لا تولّد الصور — برومبتات فقط.**
5. **صور داخل المقالات الجديدة:** اقترح لكل مقال جديد 3-5 صور من **Wikimedia Commons** بترخيص حر (CC0/CC BY/CC BY-SA/Public Domain) — **صور فوتوغرافية/توضيحية واقعية، ممنوع المخططات الصندوقية المرسومة** (box diagrams/flowcharts). اذكر في تقريرك رابط كومنز لكل صورة مع المؤلف والترخيص، وأضفها كصفوف في `docs/image-credits.md`. لا تنزّل الصور.
6. **تحديث علمي:** إذا لقيت بمقالات موجودة معلومة صارت قديمة/غير دقيقة علمياً مقارنة بالعلم الحديث، صحّحها **بتعديل موضعي دقيق** (بدون إعادة كتابة المقال، حافظ على بنية النص) وأضف `modifiedAt: '2026-11-15'` للمقال المعدل. لا تعديلات جمالية.
7. **لا تغيّر الستايل ولا التصميم ولا أي مكوّن** — بيانات فقط في ملفات الـdata + ملفات docs المذكورة.

## قيود صارمة (خطوط حمراء)
- **ممنوع النشر/الdeploy** (wrangler) — أنا (الوكيل الرئيسي) من ينشر بعد المراجعة.
- **ممنوع لمس** أي secrets أو ملفات `.env` أو `wrangler.jsonc` أو جداول قاعدة البيانات (خصوصاً newsletter_auto) أو أي كود مكوّنات/صفحات.
- **ممنوع حذف أو تعديل** عناصر موجودة في projectsData/blogArticlesData (إلا التصحيح العلمي الموضعي المذكور).
- **جلسة واحدة لهذا المجلد** — أنجز كل شي بجلسة وحدة.
- في النهاية: `git add` للتغييرات + **commit وpush إلى origin/main** (push إلزامي). رسالة commit واضحة بالإنجليزية.
- اكتب تقرير موجز في `docs/agent-tasks/2026-11-15-drive-report.md`: شو أضفت (قائمة مع slugs)، شو صححت، عدد البرومبتات، اقتراحات الصور.

## تحقق قبل الإغلاق
- `npx tsc --noEmit` يمر (أو على الأقل ما في أخطاء جديدة من ملفاتك).
- node -e تحميل الملفين والتأكد عدد العناصر زاد وأن كل عنصر جديد فيه الحقول الإلزامية، ولا slug مكرر.
