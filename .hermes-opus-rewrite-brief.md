# Opus 5.5 — Full content rewrite of 12 articles (AR + EN)

## Mission
Rewrite the full narrative of the 12 articles in BOTH `/root/technoinjaz/src/content/articles/` (Arabic) and `/root/technoinjaz/src/content/articles-en/` (English). The content is good — the *storytelling, structure and flow* are not. The site owner wants a proper re-narration (إعادة سرد) and restructuring (إعادة هيكلة), not a light edit.

## Hard rules (violations = rework)
1. **ZERO box-style anything:** no ASCII diagrams, no box-drawing characters (┌─│└┘├┤), no ```flow blocks, no fake "diagrams" made of arrows (→ chained lines as pseudo-flowchart), no lists used as fake prose.
2. **Allowed visual elements — well-used, tidy:**
   - Markdown **tables** where data genuinely compares things (specs, comparisons, steps-vs-output). Style: proper markdown tables; keep them genuinely tabular, 2-6 columns, never giant walls.
   - **Images:** keep existing image references (lines like `/images/articles/...` body images `![...](...)`) in sensible spots; do NOT invent new image paths.
   - **KaTeX math:** existing math must be preserved exactly (`$...$` / `$$...$$`). You may reflow surrounding prose but never alter the formulas.
3. **Narrative quality bar:**
   - Rich flowing engineering prose — like a well-written Arabic tech magazine feature (and its English mirror).
   - Smooth transitions between sections; each section: context → mechanism → why it matters → concrete example.
   - No filler stories, no "تخيل أنك...", no fluff, no repetition.
   - Keep technical accuracy — do not change any technical claim.
4. **Structure:** keep all headings' meaning (TOC is generated from H2/H3) but you MAY rename headings for clarity and reorder sections if the flow improves. Keep H2/H3 hierarchy; do not introduce H1.
5. **Keep exactly:** YAML frontmatter (all fields), slugs, all metadata, images paths, KaTeX formulas, `article/further-reading`-style trailing sections if present.
6. **EN file must stay a faithful mirror of the AR file** (same section order, same tables, same points) — translate your new Arabic narration naturally into English.
7. **Length:** comparable to current (±20%).

## Process

- After each article pair (AR + EN), verify: no box chars (`grep -P '[┌─│└┘├┤┬┴]' file`), no ```flow, headings intact, frontmatter unchanged, math intact.
