## 🌟 نظرة عامة (Overview)

**تكنو إنجاز (Techno Enjaz)** هي منصة ويب هندسية سينمائية متكاملة مصممة بأحدث معايير الويب العالمية لتكون البوابة الرقمية الرسمية لمكتب تكنو إنجاز الهندسي في حماة، سوريا.
تجمع المنصة بين الاستعراض الواقعي للأنظمة السحابية الحية، تغذية الريلز المرئية للمشاريع، المدونة التقنية التخصصية، ومعرض الفريق التفاعلي ثلاثي الأبعاد، مع دعم كامل للغتين (العربية والإنكليزية) والوضعين المظلم والفاتح.

---

## 🚀 الأنظمة الرائدة والمشاريع الحية (Flagship Platforms)

1. **نظام حساب السحابي (Hisab Cloud ERP)**
   - نظام مالي ومحاسبي سحابي متكامل لإدارة الشركات، الفوترة الإلكترونية، والمستودعات المتعددة.
   - مبني على معمارية Clean Architecture عالية الأداء باستخدام React و FastAPI و PostgreSQL و Redis.

2. **مختبر المحاكاة السحابي (Arduino Cloud Lab)**
   - منصة محاكاة سحابية تفاعلية لربط حساسات إنترنت الأشياء والعتاد الصلب في الزمن الحقيقي عبر WebSockets و WebAssembly.

3. **منصة إدارة المشاريع الهندسية (ProjectForge Hub)**
   - نظام متقدم لتنسيق الفرق الهندسية وتتبع دورات التطوير وربط مستودعات الأكواد.

4. **نظام شبكات الكوابل (CableXperts)**
   - أداة متخصصة لحساب مسارات الألياف الضوئية، تخطيط الشبكات، وتقدير الفواقد الضوئية بدقة.

5. **منصة الرعاية والتشخيص الذكي (Dermocean)**
   - نظام سريري مدعوم بالذكاء الاصطناعي لفحص الصور الجلدية وتنظيم السجلات الطبية.

## 🧩 الأقسام والتجارب التفاعلية (Platform Highlights)

### 1. شريط الريلز السينمائي المتسلسل (Cinema Reels Stream)
- تغذية ريلز رأسية تفاعلية تملأ الشاشة بسلاسة مع خاصية التمرير الخاطف (`scroll-snap-type: y mandatory`).
- تشغيل تفاعلي سلس مع شارة القياس عن بُعد الحية (`LIVE WALKTHROUGH`) وعداد المشاهدات المباشر.
- شريط إجراءات جانبي طافٍ: إعجاب بالنبض النيوني، درج التعليقات، حفظ في المفضلة، مشاركة سريعة، وزر إطلاق المشروع الحي.
- تنقل فوري بالأسهم والكيبورد وأزرار القفز السريع.

### 2. مدونة ومجلة المقالات الهندسية (Engineering Knowledge Hub)
- شريط تنبيه الإشعارات اللحظية.
- محرك بحث دائري ذكي مع فلترة فورية بالعناوين، الكُتّاب، والكلمات المفتاحية.
- كبسولات فرز سريعة: **الأحدث**، **الأكثر قراءة**، وقائمة منسدلة أنيقة **لكافة التصنيفات**.
- شريط وسوم شائعة قابلة للنقر والتصفية الفورية.
- **صفحة المقال الكاملة (Full-Screen Dedicated Reader)**:
  - زر عودة سلس لكافة المقالات.
  - كبسولة الكاتب الدائرية الموثقة مع تاريخ النشر وزر المشاركة.
  - نصوص غنية، اقتباسات معمارية، وكتل نصية مريحة للعين.
  - قسم تعليقات متكامل محفوظ محلياً.
  - قسم **"مقالات ذات صلة"** بالأسفل بنفس نمط البطاقات الحديثة لمواصلة القراءة.

### 3. معرض المشاريع الحية (Live Projects Showcase)
- وضعين للعرض: شريط متحرك سينمائي مستمر (Marquee Stream) أو شبكة متجاوبة (Responsive Grid).
- كبسولات فلترة الأقسام والتصنيفات.
- بطاقات مشاريع بروابط حية مباشرة، عناوين URL مدمجة، وحالات التشغيل اللحظية.

### 4. واجهة الهيرو التوسعية (ScrollExpand Hero)
- حركة توسع سينمائية تعتمد على تمرير الصفحة لربط الشعار بالواجهة التفاعلية.

### 5. قائمة الفريق ثلاثية الأبعاد (3D InfiniteMenu)
- عجلة دائرية ثلاثية الأبعاد لاستعراض أعضاء الفريق الهندسي والتنقل إلى ملفاتهم الشخصية الكاملة.

### 6. نظام الحفظ والملف الشخصي (User Profile & Saved Items)
- حفظ المشاريع والمقالات والفيديوهات محلياً في مفضلة المستخدم مع تصنيف دقيق وسرعة استرجاع.

## 🌐 الـ SEO والـ Geo Metadata وتكامل الـ AI

- **Geo-Targeting**: مهيأ جغرافياً لمدينة حماة، الجمهورية العربية السورية:
  - `geo.region`: `SY-HM`
  - `geo.placename`: `Hama, Syria`
  - `geo.position`: `35.128992;36.754001`
  - `ICBM`: `35.128992, 36.754001`
- **OpenGraph & Twitter Cards**: بطاقات تفاعلية عالية الدقة لمنصات التواصل الاجتماعي.
- **Schema.org Structured Data**: سكيما JSON-LD كاملة توثق المنظمة (`Organization`)، الخدمة المهنية (`ProfessionalService`)، والموقع الإلكتروني (`WebSite`).
- **AI Agent Context (`/llms.txt`)**: ملف توثيق مهيأ وفق معيار `llmstxt.org` يتيح لنماذج الذكاء الاصطناعي ومحركات البحث الفهم العميق لكافة خدمات وأنظمة تكنو إنجاز.
